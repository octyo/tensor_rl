## 1. What is a Tensor?

A **tensor** is a multi-dimensional array of numbers. It is a pure generalization:

| Object | Order (Rank) | Index notation | Example space |
|--------|-------------|----------------|---------------|
| Scalar | 0 | $x$ | $x \in \mathbb{R}$ |
| Vector | 1 | $v_i$ | $\mathbf{v} \in \mathbb{R}^n$ |
| Matrix | 2 | $A_{ij}$ | $A \in \mathbb{R}^{m \times n}$ |
| 3-tensor | 3 | $\mathcal{T}_{ijk}$ | $\mathcal{T} \in \mathbb{R}^{I \times J \times K}$ |
| N-tensor | N | $\mathcal{T}_{i_1 \cdots i_N}$ | $\mathcal{T} \in \mathbb{R}^{d_1 \times \cdots \times d_N}$ |

The **order** of a tensor (also called *rank*, *mode count*, or *way*) is the number of its indices.

> **Geometric intuition:** A vector is a 1D list of numbers, a matrix is a 2D grid, a 3-tensor is a cube, a 4-tensor is a hypercube, and so on.
</VSCode.Cell>
<VSCode.Cell language="python">

- **Element**: $\mathcal{T}[i, j, k]$ — a single scalar
- **Fiber** (generalization of row/column): fix all but one index, e.g. $\mathcal{T}[:, j, k]$

## 3. Basic Tensor Operations

### 3.1 Scalar Multiplication & Addition

$$(\alpha \mathcal{T})_{i_1 \cdots i_N} = \alpha \cdot \mathcal{T}_{i_1 \cdots i_N}$$

$$(\mathcal{A} + \mathcal{B})_{i_1 \cdots i_N} = \mathcal{A}_{i_1 \cdots i_N} + \mathcal{B}_{i_1 \cdots i_N}$$

### 3.2 Hadamard (Element-wise) Product

$$(\mathcal{A} \odot \mathcal{B})_{i_1 \cdots i_N} = \mathcal{A}_{i_1 \cdots i_N} \cdot \mathcal{B}_{i_1 \cdots i_N}$$

### 3.3 Outer Product — Rank-1 Tensors

For vectors $\mathbf{a} \in \mathbb{R}^I,\ \mathbf{b} \in \mathbb{R}^J,\ \mathbf{c} \in \mathbb{R}^K$:

$$\mathcal{T}_{ijk} = a_i \cdot b_j \cdot c_k$$

This produces a **rank-1 tensor**. Every tensor can be written as a *sum* of rank-1 tensors (this is the CP decomposition, covered in Notebook 2).
</VSCode.Cell>
<VSCode.Cell language="python">
a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 5.0, 6.0])
c = np.array([7.0, 8.0])

print("a =", a)
print("b =", b)
print("c =", c)

# Scalar multiplication
print("\n3 * a =", 3 * a)

# Hadamard product
hadamard = a * b
print("a ⊙ b (element-wise) =", hadamard)

# Outer product: two vectors → rank-1 matrix
outer_ab = np.outer(a, b)          # shape (3, 3)
print(f"\na ⊗ b (outer product), shape {outer_ab.shape}:")
print(outer_ab)
print(f"Matrix rank of a⊗b = {np.linalg.matrix_rank(outer_ab)} (always 1 for outer product of two vectors)")

# Rank-1 tensor: T_ijk = a_i * b_j * c_k  using einsum
rank1 = np.einsum('i,j,k->ijk', a, b, c)  # shape (3, 3, 2)
print(f"\nRank-1 tensor a⊗b⊗c, shape = {rank1.shape}")
# Spot check: T[0,0,0] must equal a[0]*b[0]*c[0]
print(f"T[0,0,0] = {rank1[0,0,0]}  (expected a[0]*b[0]*c[0] = {a[0]*b[0]*c[0]})")
print(f"T[2,2,1] = {rank1[2,2,1]}  (expected a[2]*b[2]*c[1] = {a[2]*b[2]*c[1]})")

## 4. Einstein Summation Notation

Einstein summation is the universal language of tensor operations. The rule:

> Any index that appears **exactly twice** (once as a 'dummy' index on both operands) is **summed over**.

$$c_i = \sum_j A_{ij} b_j \quad \xrightarrow{\text{Einstein notation}} \quad c_i = A_{ij} b_j$$

| Operation | Math | `np.einsum` string |
|-----------|------|--------------------|
| Matrix-vector | $c_i = A_{ij} v_j$ | `'ij,j->i'` |
| Matrix-matrix | $C_{ik} = A_{ij} B_{jk}$ | `'ij,jk->ik'` |
| Dot product | $s = v_i u_i$ | `'i,i->'` |
| Trace | $s = A_{ii}$ | `'ii->'` |
| Outer product | $C_{ij} = u_i v_j$ | `'i,j->ij'` |
| Batch matmul | $C_{bik} = A_{bij} B_{bjk}$ | `'bij,bjk->bik'` |
| Tensor contraction | $C_{il} = T_{ijk} A_{jl} B_{kl}$ | `'ijk,jl,kl->il'` |

> **Key insight:** Tensor network contraction *is* generalized einsum — each bond (edge) in the network is a contracted (summed) index.
</VSCode.Cell>
<VSCode.Cell language="python">
A = np.array([[1, 2], [3, 4]], dtype=float)
B = np.array([[5, 6], [7, 8]], dtype=float)
v = np.array([1.0, 2.0])

print("A =\n", A)
print("B =\n", B)
print("v =", v)

# Matrix-vector product
mv = np.einsum('ij,j->i', A, v)
print(f"\nA @ v via einsum = {mv}  |  verify with @: {A @ v}")

# Matrix-matrix product
mm = np.einsum('ij,jk->ik', A, B)
print(f"\nA @ B via einsum:\n{mm}\nverify:\n{A @ B}")

# Dot product
dot = np.einsum('i,i->', v, v)
print(f"\nv·v via einsum = {dot}  |  ||v||² = {np.dot(v,v)}")

# Trace
trace = np.einsum('ii->', A)
print(f"Trace(A) via einsum = {trace}  |  np.trace(A) = {np.trace(A)}")

# 3D tensor contraction: C_il = T_ijk X_jl Y_kl
T = np.random.randn(3, 4, 5)
X = np.random.randn(4, 2)
Y = np.random.randn(5, 2)
C = np.einsum('ijk,jl,kl->il', T, X, Y)
print(f"\nContraction T(3,4,5) with X(4,2) and Y(5,2) → C shape: {C.shape}")
# Verify manually for one element
c_00_manual = sum(T[0, j, k] * X[j, 0] * Y[k, 0] for j in range(4) for k in range(5))
print(f"C[0,0] from einsum = {C[0,0]:.6f}  |  manual sum = {c_00_manual:.6f}")

## 5. Tensor Unfolding (Matricization)

**Matricization** (unfolding) converts a tensor into a matrix by 'rolling out' one mode as rows and all other modes as columns.

For $\mathcal{T} \in \mathbb{R}^{I \times J \times K}$:

$$T_{(0)} \in \mathbb{R}^{I \times (JK)}, \quad T_{(1)} \in \mathbb{R}^{J \times (IK)}, \quad T_{(2)} \in \mathbb{R}^{K \times (IJ)}$$

Unfolding is fundamental to:
- **Tucker decomposition** (SVD each unfolding to find factor matrices)
- **Higher-Order SVD (HOSVD)**
- Defining **tensor rank** and **multilinear rank**

> The **Frobenius norm** $\|\mathcal{T}\|_F = \sqrt{\sum_{i_1,\ldots,i_N} \mathcal{T}_{i_1 \cdots i_N}^2}$ is **invariant** to mode of unfolding.
</VSCode.Cell>
<VSCode.Cell language="python">
T = np.arange(1, 25).reshape(2, 3, 4).astype(float)
print(f"Original tensor T, shape: {T.shape}")
print(T)

def mode_unfold(tensor, mode):
    """Mode-n matricization: returns matrix of shape (d_n, d_1*...*d_{n-1}*d_{n+1}*...*d_N)"""
    return np.moveaxis(tensor, mode, 0).reshape(tensor.shape[mode], -1)

T0 = mode_unfold(T, 0)  # (2, 12)
T1 = mode_unfold(T, 1)  # (3, 8)
T2 = mode_unfold(T, 2)  # (4, 6)

print(f"\nMode-0 unfolding T_(0): shape {T0.shape}")
print(T0)

print(f"\nMode-1 unfolding T_(1): shape {T1.shape}")
print(T1)

print(f"\nMode-2 unfolding T_(2): shape {T2.shape}")
print(T2)

# Frobenius norm is invariant to mode of unfolding
frob = np.linalg.norm(T)
print(f"\nFrobenius norm invariance check:")
print(f"  ||T||_F     = {frob:.6f}")
print(f"  ||T_(0)||_F = {np.linalg.norm(T0):.6f}")
print(f"  ||T_(1)||_F = {np.linalg.norm(T1):.6f}")
print(f"  ||T_(2)||_F = {np.linalg.norm(T2):.6f}")
print("All equal? ✓" if np.allclose([np.linalg.norm(T0), np.linalg.norm(T1), np.linalg.norm(T2)], frob) else "✗")

## 1. Matrix SVD — The Foundation

The **Singular Value Decomposition** of a matrix $A \in \mathbb{R}^{m \times n}$ is:

$$A = U \Sigma V^\top$$

where:
- $U \in \mathbb{R}^{m \times m}$ — left singular vectors (orthonormal columns)
- $\Sigma \in \mathbb{R}^{m \times n}$ — diagonal matrix of **singular values** $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$
- $V \in \mathbb{R}^{n \times n}$ — right singular vectors (orthonormal columns)

**Truncated SVD (rank-$r$ approximation):** Keep only the top $r$ singular values:

$$A \approx A_r = U_r \Sigma_r V_r^\top = \sum_{k=1}^{r} \sigma_k \mathbf{u}_k \mathbf{v}_k^\top$$

This is the **best rank-$r$ approximation** in Frobenius norm (Eckart-Young theorem).
</VSCode.Cell>
<VSCode.Cell language="python">
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(0)

# Create a low-rank-ish matrix to decompose
m, n = 8, 6
A = np.random.randn(m, n)

# Full SVD
U, s, Vt = np.linalg.svd(A, full_matrices=True)
print(f"A shape: {A.shape}")
print(f"U shape: {U.shape}  |  s shape: {s.shape}  |  Vt shape: {Vt.shape}")
print(f"\nSingular values: {s.round(4)}")

# Verify: A ≈ U @ diag(s) @ Vt
Sigma = np.zeros_like(A)
Sigma[:len(s), :len(s)] = np.diag(s)
A_reconstructed = U @ Sigma @ Vt
print(f"\nReconstruction error (should be ~0): {np.linalg.norm(A - A_reconstructed):.2e}")

# Truncated SVD: rank-r approximation
def truncated_svd(A, r):
    U, s, Vt = np.linalg.svd(A, full_matrices=False)
    return U[:, :r], s[:r], Vt[:r, :]

print("\n--- Rank-r approximation errors ---")
for r in [1, 2, 3, 4, m]:
    Ur, sr, Vtr = truncated_svd(A, r)
    Ar = Ur @ np.diag(sr) @ Vtr
    err = np.linalg.norm(A - Ar, 'fro')
    params_orig = m * n
    params_approx = r * (m + 1 + n)  # U_r + s_r + Vt_r
    print(f"  r={r}: ||A - A_r||_F = {err:.4f}  |  params: {params_orig} → {params_approx}")

# Plot singular value decay
plt.figure(figsize=(8, 3))
plt.subplot(1, 2, 1)
plt.bar(range(1, len(s)+1), s, color='steelblue')
plt.xlabel('Index k'); plt.ylabel('Singular value σ_k')
plt.title('Singular Value Spectrum')

plt.subplot(1, 2, 2)
cumvar = np.cumsum(s**2) / np.sum(s**2) * 100
plt.plot(range(1, len(s)+1), cumvar, 'o-', color='orangered')
plt.xlabel('Rank r'); plt.ylabel('Variance explained (%)')
plt.title('Cumulative Variance Explained')
plt.tight_layout()
plt.show()

## 2. CP Decomposition (PARAFAC)

The **Canonical Polyadic (CP)** decomposition expresses a tensor as a **sum of rank-1 tensors**:

$$\mathcal{T} \approx \sum_{r=1}^{R} \lambda_r \; \mathbf{a}_r^{(1)} \otimes \mathbf{a}_r^{(2)} \otimes \cdots \otimes \mathbf{a}_r^{(N)}$$

For a 3D tensor of shape $(I, J, K)$ with rank $R$:

$$\mathcal{T}_{ijk} \approx \sum_{r=1}^{R} \lambda_r \; a^{(1)}_{ir} \; a^{(2)}_{jr} \; a^{(3)}_{kr}$$

**Factor matrices:** $A^{(1)} \in \mathbb{R}^{I \times R},\ A^{(2)} \in \mathbb{R}^{J \times R},\ A^{(3)} \in \mathbb{R}^{K \times R}$

**Compression:** Original $IJK$ parameters → $R(I + J + K)$ parameters.

**Algorithm:** Alternating Least Squares (ALS) — fix all factors but one, solve linear system, repeat.
</VSCode.Cell>
<VSCode.Cell language="python">
import tensorly as tl
from tensorly.decomposition import parafac
from tensorly import cp_to_tensor

np.random.seed(42)

# ── Build a ground-truth rank-3 tensor ───────────────────────────────────────
I, J, K = 10, 8, 6
R_true = 3

# Generate random rank-3 tensor: T = sum of 3 rank-1 terms
A1 = np.random.randn(I, R_true)
A2 = np.random.randn(J, R_true)
A3 = np.random.randn(K, R_true)
weights_true = np.ones(R_true)

# Reconstruct via einsum: T_ijk = sum_r A1_ir * A2_jr * A3_kr
T_true = np.einsum('ir,jr,kr->ijk', A1, A2, A3)
T_noisy = T_true + 0.1 * np.random.randn(*T_true.shape)

print(f"True tensor shape: {T_noisy.shape}")
print(f"True rank: {R_true}")
print(f"Original parameters: {T_noisy.size}")

# ── Fit CP decomposition with tensorly ───────────────────────────────────────
for R in [1, 2, 3, 5, 10]:
    cp_factors = parafac(tl.tensor(T_noisy), rank=R, n_iter_max=200, init='svd', random_state=0)
    T_approx = cp_to_tensor(cp_factors)
    err = np.linalg.norm(T_noisy - T_approx) / np.linalg.norm(T_noisy)
    params = R * (I + J + K)
    print(f"  Rank R={R:2d}: relative error = {err:.4f}  |  params: {params:4d} (vs {T_noisy.size} original)")

# ── Inspect the factor matrices at R=3 ───────────────────────────────────────
cp_factors = parafac(tl.tensor(T_noisy), rank=R_true, n_iter_max=500, init='svd', random_state=0)
print(f"\nCP factors at R={R_true}:")
for i, fac in enumerate(cp_factors.factors):
    print(f"  Factor A^({i+1}) shape: {fac.shape}")
print(f"  Weights (λ): {cp_factors.weights.round(4)}")

## 3. Tucker Decomposition

The **Tucker decomposition** generalizes SVD to N-dimensional tensors:

$$\mathcal{T} \approx \mathcal{G} \times_1 A^{(1)} \times_2 A^{(2)} \times_3 A^{(3)}$$

where:
- $\mathcal{G} \in \mathbb{R}^{r_1 \times r_2 \times r_3}$ — **core tensor** (captures interactions between modes)
- $A^{(n)} \in \mathbb{R}^{d_n \times r_n}$ — **factor matrix** for mode $n$ (orthonormal columns)
- $r_n$ — rank along mode $n$ (the **multilinear rank**)

The **mode-$n$ product** $\mathcal{T} \times_n A$ is defined elementwise as:

$$(\mathcal{T} \times_n A)_{i_1 \cdots i_{n-1} j i_{n+1} \cdots i_N} = \sum_{i_n} \mathcal{T}_{i_1 \cdots i_N} A_{j, i_n}$$

**Compression:** $(d_1 d_2 d_3)$ → $(r_1 r_2 r_3 + r_1 d_1 + r_2 d_2 + r_3 d_3)$

**HOSVD** (Higher-Order SVD): Compute Tucker by doing SVD on each mode unfolding.
</VSCode.Cell>
<VSCode.Cell language="python">
from tensorly.decomposition import tucker
from tensorly import tucker_to_tensor

np.random.seed(7)
T = np.random.randn(12, 10, 8)
print(f"Original tensor shape: {T.shape}  |  elements: {T.size}")

print("\n--- Tucker decomposition with varying ranks ---")
for ranks in [(2,2,2), (4,4,4), (6,6,6), (8,8,6)]:
    core, factors = tucker(tl.tensor(T), rank=list(ranks), n_iter_max=200, init='svd', random_state=0)
    T_approx = tucker_to_tensor((core, factors))
    err = np.linalg.norm(T - T_approx) / np.linalg.norm(T)
    n_orig = T.size
    n_tucker = core.size + sum(f.shape[0]*f.shape[1] for f in factors)
    ratio = n_orig / n_tucker
    print(f"  ranks={ranks}: rel. error = {err:.4f}  |  params: {n_orig} → {n_tucker}  (compression {ratio:.1f}x)")

# ── Inspect the decomposition at moderate ranks ───────────────────────────────
ranks = (4, 4, 4)
core, factors = tucker(tl.tensor(T), rank=list(ranks), n_iter_max=200, init='svd', random_state=0)

print(f"  Core tensor shape: {core.shape}")

# Verify orthonormality of factor columns

## 4. Tensor Train (TT) Decomposition / Matrix Product State (MPS)

The **Tensor Train (TT)** decomposition (also called **Matrix Product State** in physics) represents an N-dimensional tensor as a chain of 3-dimensional core tensors:

$$\mathcal{T}_{i_1 i_2 \cdots i_N} = \sum_{\alpha_0, \alpha_1, \ldots, \alpha_N} G^{(1)}_{\alpha_0 i_1 \alpha_1} \cdot G^{(2)}_{\alpha_1 i_2 \alpha_2} \cdots G^{(N)}_{\alpha_{N-1} i_N \alpha_N}$$

Since $\alpha_0 = \alpha_N = 1$ (boundary conditions), this simplifies to a **product of matrices**:
$$\mathcal{T}_{i_1, \ldots, i_N} = G^{(1)}[i_1] \cdot G^{(2)}[i_2] \cdots G^{(N)}[i_N]$$

Each $G^{(k)} \in \mathbb{R}^{r_{k-1} \times d_k \times r_k}$ is a 3D core tensor (or "bond tensor").

**TT-ranks** $(r_0, r_1, \ldots, r_N)$ with $r_0 = r_N = 1$ control the compression.

**Compression:** $\prod_k d_k$ → $\sum_k r_{k-1} d_k r_k$

This is **exponentially more efficient** for many structured tensors (quantum states, smooth functions).
</VSCode.Cell>
<VSCode.Cell language="python">
from tensorly.decomposition import tensor_train
from tensorly.tt_tensor import tt_to_tensor

    err = np.linalg.norm(T - T_approx) / np.linalg.norm(T)
    actual_ranks = [f.shape[0] for f in tt_factors] + [tt_factors[-1].shape[-1]]
    params = sum(f.size for f in tt_factors)
    print(f"  max_rank={max_rank:2d}: rel. error = {err:.4f}  |  TT-ranks={actual_ranks}  |  params={params}")

## 5. Comparing Decompositions

| Decomposition | Formula | Parameters | Best for |
|--------------|---------|------------|---------|
| **CP** | $\sum_r \lambda_r \mathbf{a}^{(1)}_r \otimes \cdots \otimes \mathbf{a}^{(N)}_r$ | $R \sum_n d_n$ | Low-rank, sparse interactions |
| **Tucker** | $\mathcal{G} \times_1 A^{(1)} \cdots \times_N A^{(N)}$ | $\prod_n r_n + \sum_n r_n d_n$ | Full multilinear structure |
| **TT / MPS** | $G^{(1)}[i_1] \cdots G^{(N)}[i_N]$ | $\sum_n r_{n-1} d_n r_n$ | Sequential/chain structure |

The TT decomposition has **linear scaling in N** (number of dimensions), making it ideal for very high-dimensional tensors.
</VSCode.Cell>

## Summary

We covered the three main tensor decompositions:

1. **SVD** — optimal low-rank matrix approximation; the building block of all tensor methods
2. **CP (PARAFAC)** — sum of rank-1 terms; minimal parameter count; computed via ALS
3. **Tucker** — core tensor + factor matrices; full multilinear structure; computed via HOSVD
4. **Tensor Train (TT/MPS)** — chain of 3D cores; linear in N; ideal for high-dimensional tensors

### Error-Compression Trade-off
- Lower rank → more compression → higher reconstruction error
- Choosing rank is the key hyperparameter: look for a "knee" in the singular value spectrum

## 1. What is a Tensor Network?

A **tensor network** is a set of tensors connected by shared indices. It can be represented as a graph where:
- **Nodes** = tensors
- **Edges** = indices (dimensions)
  - An edge connecting two nodes = a **contracted** (summed) index (bond)
  - A dangling (open) edge = a **free** index of the overall network

### Graphical Notation

```
    [A]───[B]                 A_ij B_jk = C_ik
     i  j  k
```

- A box/circle = a tensor
- A line connecting two boxes = a shared, contracted index (bond)
- A dangling line = a free index of the result

The **bond dimension** (dimension of a contracted index) controls expressiveness and cost.

**Contraction cost:** Contracting two tensors sharing a bond of dimension $\chi$ costs $O(\chi \cdot \text{remaining dimensions})$.
</VSCode.Cell>
<VSCode.Cell language="python">
import numpy as np
import tensornetwork as tn

# ── Simple 2-node contraction ─────────────────────────────────────────────────
# A(i,j) * B(j,k) = C(i,k)   [matrix multiplication as a tensor network]
A_data = np.random.randn(3, 4)
B_data = np.random.randn(4, 5)

A = tn.Node(A_data, name="A")
B = tn.Node(B_data, name="B")

# Connect shared index j (axis 1 of A, axis 0 of B)
edge_j = tn.connect(A[1], B[0])

print(f"Node A: shape {A.shape}, edges: {A.edges}")
print(f"Node B: shape {B.shape}, edges: {B.edges}")
print(f"Shared edge (j): {edge_j}")

# Contract the network over edge j
C_node = tn.contract(edge_j)
print(f"\nContracted node C: shape {C_node.shape}")

# Verify: same as matrix multiplication
C_numpy = A_data @ B_data
print(f"NumPy C = A @ B shape: {C_numpy.shape}")
print(f"Match: {np.allclose(C_node.tensor, C_numpy)}")

## 2. Matrix Product State (MPS) / Tensor Train

The **MPS** (Matrix Product State) is one of the most important tensor network structures. It represents an N-index tensor as a **chain** of 3-index tensors:

```
  i1   i2   i3   i4
  |    |    |    |
[A1]─[A2]─[A3]─[A4]
α0  α1  α2  α3  α4
```

where $\alpha_0 = \alpha_N = 1$ (boundary), $\alpha_k$ are virtual (bond) indices.

$$\mathcal{T}_{i_1 i_2 i_3 i_4} = \sum_{\alpha_1, \alpha_2, \alpha_3} A^{(1)}_{1, i_1, \alpha_1} A^{(2)}_{\alpha_1, i_2, \alpha_2} A^{(3)}_{\alpha_2, i_3, \alpha_3} A^{(4)}_{\alpha_3, i_4, 1}$$

**Bond dimension** $\chi$ = max dimension of bond indices. Larger $\chi$ → better approximation, more parameters.

When the tensor represents a quantum state, this is called an **MPS** (Matrix Product State). In ML, it is called the **Tensor Train** representation.
</VSCode.Cell>
<VSCode.Cell language="python">
# ── Build an MPS manually with tensornetwork ──────────────────────────────────
np.random.seed(42)

# Physical dimensions (like feature dimensions in ML)
d = [3, 4, 5, 4]     # d_1, d_2, d_3, d_4
# Bond dimensions
chi = [1, 3, 3, 3, 1]  # r_0, r_1, r_2, r_3, r_4

N = len(d)
print("MPS structure:")
print(f"  Physical dims: {d}")
print(f"  Bond dims:     {chi}")

# Create cores G^(k) of shape (chi_{k-1}, d_k, chi_k)
cores = []
for k in range(N):
    shape = (chi[k], d[k], chi[k+1])
    core_data = np.random.randn(*shape) * 0.5
    cores.append(core_data)
    print(f"  Core G^({k+1}) shape: {shape}")

# Build TN and contract to get full tensor
def mps_to_tensor(cores):
    """Contract an MPS chain to produce the full tensor."""
    # Start with first core (1, d0, r1) -> (d0, r1)
    result = cores[0][0, :, :]                    # shape: (d_0, chi_1)
    for core in cores[1:]:                         # core shape: (chi_k, d_k, chi_{k+1})
        # result shape: (..., chi_k), contract over last axis of result with first axis of core
        result = np.tensordot(result, core, axes=([-1], [0]))  # (..., d_k, chi_{k+1})
    return result[..., 0]  # drop final bond dim (=1)

T_mps = mps_to_tensor(cores)
print(f"\nFull tensor from MPS, shape: {T_mps.shape}")
print(f"Original size: {np.prod(d)}  |  MPS params: {sum(c.size for c in cores)}")
print(f"Compression ratio: {np.prod(d)/sum(c.size for c in cores):.2f}x")

# ── Now use tensornetwork library to do the same ─────────────────────────────
tn_nodes = [tn.Node(c, name=f"G{k}") for k, c in enumerate(cores)]

# Connect bonds: right edge of G^(k) to left edge of G^(k+1)
for k in range(N - 1):
    tn.connect(tn_nodes[k][2], tn_nodes[k+1][0])  # right bond of core k ↔ left bond of core k+1

print(f"\nTensorNetwork nodes created: {[n.name for n in tn_nodes]}")
print("Bonds connected: G0─G1─G2─G3")

## 3. Contracting a Tensor Network

In a tensor network, **contraction** means summing over all shared (bond) indices to produce the final result.

**Order matters for efficiency!** Different contraction orders have different computational costs.

For a chain MPS, left-to-right sequential contraction is $O(N \chi^2 d)$, which is linear in $N$ — this is the key efficiency advantage.

**Optimal contraction order** is NP-hard in general, but good heuristics exist (e.g., `opt_einsum`).
</VSCode.Cell>
<VSCode.Cell language="python">
import opt_einsum as oe

np.random.seed(0)

# ── opt_einsum: find optimal contraction path ─────────────────────────────────
# Contract T_abcd = A_ab * B_bc * C_cd * D_de
A = np.random.randn(5, 10)
B = np.random.randn(10, 8)
C = np.random.randn(8, 6)
D = np.random.randn(6, 4)

# Naive: full pairwise contraction
result_naive = A @ B @ C @ D
print(f"Chain A(5,10)─B(10,8)─C(8,6)─D(6,4) → shape {result_naive.shape}")

# opt_einsum: finds optimal order
expr = 'ab,bc,cd,de->ae'
result_oe = oe.contract(expr, A, B, C, D)
print(f"opt_einsum result shape: {result_oe.shape}")
print(f"Results match: {np.allclose(result_naive, result_oe)}")

# Show the optimal contraction path
path, path_info = oe.contract_path(expr, A, B, C, D, optimize='optimal')
print(f"\nOptimal contraction path: {path}")
print(f"FLOP count (optimal): {path_info.opt_cost:.0f}")
print(path_info)

# ── More complex: 3D tensor network contraction ───────────────────────────────
# Contraction of two MPS (inner product <ψ|φ>)
np.random.seed(1)
d_phys = 3
chi_bond = 4

# Build two random MPS

        for k in range(N_sites)]

## 4. Tree Tensor Networks (TTN)

A **Tree Tensor Network** arranges tensors in a tree hierarchy. Unlike MPS chains, TTN can represent **hierarchical correlations** more efficiently.

```
              [root]
             /      \
          [L1]      [R1]
         /    \    /    \
        i1   i2  i3    i4
```

**Properties:**
- No loops → contraction in $O(N)$ sweeps (message-passing / belief propagation)
- Better suited for data with hierarchical structure (images, hierarchical features)
- **MERA** (Multi-scale Entanglement Renormalization Ansatz) extends TTN with additional disentanglers

**Bond dimension** $\chi$ still controls the expressiveness trade-off.
</VSCode.Cell>
<VSCode.Cell language="python">
# ── Build a simple binary Tree Tensor Network ─────────────────────────────────
np.random.seed(5)

chi_bond = 4
d_phys = 3

# Leaf tensors: shape (d_phys, chi_bond)
leaf_L1 = np.random.randn(d_phys, chi_bond)   # site 0
leaf_L2 = np.random.randn(d_phys, chi_bond)   # site 1
leaf_R1 = np.random.randn(d_phys, chi_bond)   # site 2
leaf_R2 = np.random.randn(d_phys, chi_bond)   # site 3

# Internal tensors: shape (chi_bond, chi_bond, chi_bond) [left_bond, right_bond, parent_bond]
internal_L = np.random.randn(chi_bond, chi_bond, chi_bond)
internal_R = np.random.randn(chi_bond, chi_bond, chi_bond)

# Root tensor: shape (chi_bond, chi_bond)  → scalar output
root = np.random.randn(chi_bond, chi_bond)

print("Tree Tensor Network structure:")
print(f"  Leaves:   L1{leaf_L1.shape}, L2{leaf_L2.shape}, R1{leaf_R1.shape}, R2{leaf_R2.shape}")
print(f"  Internal: Left{internal_L.shape}, Right{internal_R.shape}")
print(f"  Root:     {root.shape}")
print()
print("Contraction tree:")
print("              [root]  2,2")
print("             /      \\")
print("         [left]     [right]  4,4,4")
print("        /     \\    /     \\")
print("       i0    i1   i2    i3  (3,4 leaves)")

# Contract the tree bottom-up
# Step 1: Contract leaves into internal nodes
left_branch = np.einsum('ia, jb, abc -> ijc', leaf_L1, leaf_L2, internal_L)
right_branch = np.einsum('ia, jb, abc -> ijc', leaf_R1, leaf_R2, internal_R)
print(f"\nLeft branch (after contracting L1,L2 with internal_L): {left_branch.shape}")
print(f"Right branch (after contracting R1,R2 with internal_R): {right_branch.shape}")

# Step 2: Contract branches with root
result = np.einsum('ija, jkb, ab -> ijk', left_branch, right_branch, root)
# Wait - let me simplify to scalar for cleaner demonstration
scalar = np.einsum('ija, klb, ab -> ', left_branch, right_branch, root)
print(f"\nContracted scalar output (inner product): {scalar:.4f}")

              internal_L.size + internal_R.size + root.size)
full_tensor_size = d_phys**4
print(f"\nTTN parameters: {params_ttn}")

## Summary

Tensor networks are a powerful framework for representing and computing with structured high-dimensional tensors:

1. **Graph structure:** nodes = tensors, edges = indices; contracted edges = bonds
2. **MPS/TT:** linear chain — optimal for 1D and sequential data; scales linearly in N
3. **TTN:** binary tree — captures hierarchical correlations; better for structured data
4. **Contraction order** dramatically affects computational cost — `opt_einsum` finds efficient paths
5. `tensornetwork` (Google) — low-level graph-based API  
6. `quimb` — high-level MPS/MPO with quantum information algorithms

| Structure | Best for | Bond dimension governs |
|-----------|----------|----------------------|
| MPS | sequences, chains | 1D quantum/classical correlations |
| TTN | hierarchical data | hierarchical correlations |
| PEPS | 2D grids, images | 2D entanglement |
| MERA | scale-invariant data | multi-scale structure |

## 1. Why Tensors in Machine Learning?

A fully-connected layer maps input $\mathbf{x} \in \mathbb{R}^n$ to output $\mathbf{y} \in \mathbb{R}^m$:

$$\mathbf{y} = W \mathbf{x} + \mathbf{b}, \quad W \in \mathbb{R}^{m \times n}$$

For large layers (e.g., $n = m = 1000$), $W$ has $10^6$ parameters.

**Tensorized approach:** Reshape $W$ as a tensor $\mathcal{W} \in \mathbb{R}^{m_1 \cdots m_M \times n_1 \cdots n_N}$ and apply a TT (or Tucker) decomposition:

$$W \approx W_{\text{TT}}, \quad \text{params: } 10^6 \to O(r^2 d) \text{ with } r \ll n, m$$

This can provide **10x–1000x compression** with small accuracy loss.

**Other applications:**
- Tensorized embeddings (language models, recommender systems)
- Tensor regression (multilinear outputs)
- Tensor networks as generative models / classifiers
</VSCode.Cell>
<VSCode.Cell language="python">
import numpy as np
import torch
import torch.nn as nn
import tensorly as tl
from tensorly.decomposition import tucker, tensor_train
from tensorly import tucker_to_tensor
from tensorly.tt_tensor import tt_to_tensor

tl.set_backend('numpy')
np.random.seed(42)
torch.manual_seed(42)

# ── Weight matrix compression demo ───────────────────────────────────────────
print("=== Weight Matrix Compression ===\n")

# Simulate a large FC layer weight matrix
m, n = 64, 64
W = np.random.randn(m, n)
print(f"Weight matrix W: shape {W.shape}, params = {W.size}")

# Reshape as 4D tensor: (8, 8, 8, 8)
W_tensor = W.reshape(8, 8, 8, 8)
print(f"Reshaped as tensor: {W_tensor.shape}")

print("\n--- Tucker Compression ---")
for ranks in [(2,2,2,2), (4,4,4,4), (6,6,6,6)]:
    core, facs = tucker(tl.tensor(W_tensor), rank=list(ranks), n_iter_max=200, init='svd', random_state=0)
    W_approx = tucker_to_tensor((core, facs)).reshape(m, n)
    err = np.linalg.norm(W - W_approx, 'fro') / np.linalg.norm(W, 'fro')
    params_tucker = core.size + sum(f.shape[0]*f.shape[1] for f in facs)
    print(f"  ranks={ranks}: rel. error = {err:.4f}  params {W.size} → {params_tucker}  ({W.size/params_tucker:.1f}x)")

print("\n--- TT Compression ---")
for rmax in [2, 4, 8, 16]:
    cores = tensor_train(tl.tensor(W_tensor), rank=rmax)
    W_approx = tt_to_tensor(cores).reshape(m, n)
    err = np.linalg.norm(W - W_approx, 'fro') / np.linalg.norm(W, 'fro')
    params_tt = sum(c.size for c in cores)
    print(f"  r_max={rmax:2d}: rel. error = {err:.4f}  params {W.size} → {params_tt}  ({W.size/params_tt:.1f}x)")

## 2. Tensorized Linear Layer (TT-Layer)

A **TT-Layer** replaces a standard $\mathbb{R}^n \to \mathbb{R}^m$ linear layer with a weight tensor in TT format.

Given input reshaped as $\mathcal{X} \in \mathbb{R}^{n_1 \times \cdots \times n_N}$ and TT weight cores $G^{(1)}, \ldots, G^{(N)}$:

$$y_{j_1 \cdots j_M} = \sum_{i_1, \ldots, i_N} \mathcal{W}_{j_1 \cdots j_M, i_1 \cdots i_N} \cdot x_{i_1 \cdots i_N}$$

where $\mathcal{W}$ is represented in TT format. This is the **TT-Matrix** (also called TT-FC layer).
</VSCode.Cell>

# ── tntorch: Fit TT to data ───────────────────────────────────────────────────
print("=== Fitting TT approximation to a tensor ===\n")

torch.manual_seed(42)
np.random.seed(42)

# A structured target tensor: sum of smooth functions
shape = (20, 20, 20)
x = torch.linspace(0, 1, 20)
# T_ijk = sin(π*x_i) * cos(π*x_j) * exp(-x_k)  ← low-rank structure
T_target = torch.outer(torch.sin(np.pi * x), torch.cos(np.pi * x)).unsqueeze(2) * torch.exp(-x).unsqueeze(0).unsqueeze(0)
print(f"Target tensor shape: {T_target.shape}")
print(f"Target tensor values range: [{T_target.min():.3f}, {T_target.max():.3f}]")

# Fit TT with increasing rank
for tt_rank in [1, 2, 3, 5]:
    tt_approx = tnt.rand(shape, ranks_tt=tt_rank)
    # Optimize using gradient descent
    optimizer = torch.optim.Adam(tt_approx.parameters(), lr=1e-2)
    
    for step in range(200):
        optimizer.zero_grad()
        T_approx = tt_approx.torch()
        loss = torch.norm(T_approx - T_target)**2
        loss.backward()
        optimizer.step()
    
    final_err = (torch.norm(tt_approx.torch() - T_target) / torch.norm(T_target)).item()
    params = sum(c.numel() for c in tt_approx.cores)
    print(f"  TT-rank={tt_rank}: rel. error = {final_err:.5f}  params = {params}")

## 3. Tensor Network Classifier (MPS Classifier)

An MPS can be used directly as a **classifier** for fixed-length feature vectors. The idea:

1. Map each input feature $x_k$ to a local feature vector $\phi(x_k) \in \mathbb{R}^d$ (feature map)
2. The MPS weight tensor $\mathcal{W}$ acts on the product of all local features
3. Output: $f(x) = \mathcal{W} \cdot \bigotimes_k \phi(x_k)$

For a 2D binary classification:
$$f(\mathbf{x}) = \sum_{i_1, \ldots, i_N} W_{i_1 \cdots i_N} \prod_k \phi_k(x_k)_{i_k}$$

This is equivalent to contracting the MPS with all feature vectors simultaneously.

**Advantage:** The model is linear in the exponentially large feature space $\bigotimes_k \mathbb{R}^d$, but parameterized with $O(N \chi^2 d)$ parameters.
</VSCode.Cell>
<VSCode.Cell language="python">

class MLP(nn.Module):
    def __init__(self, n_in, hidden, n_out):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_in, hidden), nn.ReLU(),
            nn.Linear(hidden, n_out)
        )
    def forward(self, x):
        return self.net(x)

def train_model(model, X_tr, y_tr, X_te, y_te, epochs=300, lr=1e-2):
    opt = torch.optim.Adam(model.parameters(), lr=lr)
    for epoch in range(epochs):
        model.train()
        logits = model(X_tr)
        loss = F.cross_entropy(logits, y_tr)
        opt.zero_grad(); loss.backward(); opt.step()
    model.eval()
    with torch.no_grad():
        acc = (model(X_te).argmax(1) == y_te).float().mean()
    return acc.item()

mlp = MLP(n_features, 32, n_classes)

mlp_acc = train_model(mlp, X_train, y_train, X_test, y_test)

phi = torch.stack([torch.ones(n_features), X_train.T], dim=-1)  # shape (n_features, n_samples, d_local)
# reshape: (n_samples, n_features, d_local)
phi_train = torch.stack([torch.ones(X_train.shape[0], n_features), X_train], dim=-1)
phi_test  = torch.stack([torch.ones(X_test.shape[0], n_features), X_test], dim=-1)

print(f"\nFeature maps shape: {phi_train.shape}  [n_samples × n_features × d_local]")
print("(Feature map: phi(x_k) = [1, x_k] — simplest possible local encoding)")

# Use simple logistic regression on flattened features as TT proxy
from sklearn.linear_model import LogisticRegression

lr_model = LogisticRegression(max_iter=1000)
lr_model.fit(phi_flat_train, y_train.numpy())
lr_acc = lr_model.score(phi_flat_test, y_test.numpy())
